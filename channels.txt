# ============================================================
# SlugTube Channels
# ============================================================
# One channel per line. Two formats are accepted:
#
#   https://www.youtube.com/@SomeChannel/videos
#   https://www.youtube.com/@SomeChannel/videos|Folder Name
#
# The second form pins the folder name. Use it when YouTube's channel name
# contains characters your filesystem dislikes, or when you simply want a
# tidier folder. Without it, SlugTube uses the channel name as returned by
# YouTube, which can change.
#
# Playlists work too:
#   https://www.youtube.com/playlist?list=PLxxxxxxxx|My Playlist
#
# Lines starting with # are ignored. Blank lines are ignored.
#
# You can also add channels from the web UI, which writes to this file.
# ============================================================
